# Фотокомикс — фотокнига / комикс (PWA)

Веб-приложение, которое одновременно работает как приложение для телефона (PWA).
Помогает собрать **фотокнигу или комикс**: снимаете кадры на камеру, выбираете
лучший дубль и подписываете каждую страницу подсказкой о том, каким должен быть кадр.

## Как пользоваться

- **3 страницы по умолчанию** с готовыми подсказками (завязка → развитие → развязка).
- **Свайп влево / вправо** — переход между страницами (на компьютере — стрелки ←/→).
  Точки сверху показывают, на какой вы странице, и по ним можно перейти.
- **Кнопка съёмки** (большая круглая внизу) открывает камеру и заполняет текущую
  страницу кадром. Можно также нажать на пустую рамку.
- **Несколько дублей на страницу**: снимайте сколько нужно. **Свайп вверх / вниз**
  по кадру переключает дубли (на компьютере — стрелки ↑/↓). Активный дубль
  показан точками справа и подписью «дубль N/M». Ненужный дубль удаляется кнопкой
  на самом кадре.
- **Текст-подсказка** под каждым кадром редактируется прямо в приложении и
  **сохраняется автоматически** — при следующем открытии всё на месте.
- **Меню** (☰ справа сверху): добавить страницу, очистить кадры страницы,
  удалить страницу, начать заново. Кнопка «＋» внизу добавляет страницу после текущей.

## Где хранятся данные

Кадры и тексты сохраняются локально на устройстве через **IndexedDB** —
ничего не загружается в сеть, всё остаётся в браузере/приложении и переживает
перезапуск. Съёмка и обработка идут прямо на устройстве.

## Запуск локально

Камера работает только по HTTPS или через `localhost` (не при открытии файла напрямую).

```bash
python -m http.server 8080
```

Затем откройте http://localhost:8080

В VS Code можно использовать расширение Live Server.

## Размещение

Подойдут GitHub Pages, Netlify, Cloudflare Pages, Vercel или любой HTTPS-хостинг.
После установки как PWA приложение открывается на весь экран и работает офлайн.

## Файлы

- `index.html` — весь интерфейс, страницы-свайпы, камера, выбор дублей и подписи
- `manifest.json` — настройки устанавливаемого PWA
- `service-worker.js` — кэширование оболочки для офлайн-работы
- `icon.svg` — иконка приложения
